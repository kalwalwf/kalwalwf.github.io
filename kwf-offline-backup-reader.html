KWF Offline Backup Reader

This tool decrypts your .kwfbackup on your own computer. Save this HTML file on your hard drive while GitHub and Supabase are working. It has no external scripts or network requests.

Private data warning: The resulting ZIP is NOT encrypted and contains donors' and families' personal information, financial records and any backed-up receipts. Use only on a trusted computer. Store the original encrypted backup separately and delete the unencrypted ZIP after recovery.

Restoration instructions

  1. When the original Supabase project still works, sign in as Owner at KWF and use My Account → Backup & Restore → Preview / Restore. That imports only missing database records, without overwriting existing records.
  2. For a new Supabase project, a qualified administrator must first reconstruct the SQL schema, Auth users and storage policies. This ZIP does not contain reusable passwords or service-role credentials.
  3. Back up the GitHub repositories' source ZIP files separately. This decrypted ZIP contains database records and receipts, not the GitHub website source.
Format: AES-256-GCM authenticated encryption, PBKDF2-SHA256 (310,000 iterations). All decryption happens in this browser tab.
